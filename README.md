## Selected work

### [Cooling Schedule Explorer](https://github.com/brunowe/simulation-fec/pull/26)

A portfolio-focused rebuild of an early React and p5.js prototype. It converts initial temperature, final temperature, and cooling rate into a validated linear schedule, an accessible SVG curve, and a conceptual visualization.

- React 19, Vite 8, and p5.js 2
- Accessible controls, playback, scrubbing, and responsive layout
- 12 automated tests and GitHub Actions CI
- Illustrative and non-predictive by design
- Status: [draft modernization in PR #26](https://github.com/brunowe/simulation-fec/pull/26)
